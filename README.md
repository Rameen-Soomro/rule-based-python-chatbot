# Rule-Based Python Chatbot

A simple rule-based chatbot built with Python that responds to user messages using predefined rules and responses.

## Features

- Responds to common user messages
- Simple and beginner-friendly
- Built using Python
- Runs directly in the terminal

## Technologies Used

- Python

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run:

```bash
python chatbot.py
